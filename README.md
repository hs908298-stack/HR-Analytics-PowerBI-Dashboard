# HR Analytics Dashboard | Power BI

## Project Overview
An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze employee data and provide meaningful workforce insights.

## Key Features
- Total Employee Count
- Department-wise Employee Distribution
- Employee Location Analysis
- Workforce Overview
- Interactive Charts and Slicers
- Multi-page Dashboard

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning
